## 🔬 Research Focus

I work at the intersection of **hardware-accelerated computing**, **real-time image processing**, and **practical robotic perception**. My primary interest is in extracting maximum performance from heterogeneous embedded architectures, particularly the NVIDIA Jetson family, to enable sophisticated vision algorithms on power-constrained platforms.

- **Embedded Vision** — Real-time pipelines for edge deployment
- **GPU-Accelerated Algorithms** — CUDA-based implementations of classical CV operators
- **Hardware Acceleration** — GStreamer, NVVIDCONV, NVIDIA Argus, TensorRT
- **Robotic Perception** — Visual odometry, marker-based localization, tracking

## 🚀 Featured Project

### [Jetson CSI + CUDA Vision Pipeline](https://github.com/taloy6/jetson-csi-cuda-vision)

A modular, real-time vision framework for the NVIDIA Jetson TX2 NX. Integrates hardware-accelerated CSI capture, CUDA-based processing, and browser-based remote visualization into a production-ready pipeline.

| Metric | Value |
| :--- | :--- |
| **Sustained Frame Rate** | 60 FPS @ 1280×720 |
| **GPU Utilization** | ~24% |
| **System Power** | ~5.5 W |
| **End-to-End Latency** | ~9 ms |
| **Architecture** | Three-tier async, Pimpl, zero-copy transfer |

The repository is documented with a full optimization history, architectural rationale, and reproducible benchmarks. It is intended as a reference for engineers building edge vision systems on the Jetson platform.
