<h3>Architecture Highlights</h3>

<ul>
<li>Three-tier asynchronous pipeline: acquisition / processing / transmission</li>
<li>Zero-copy frame transfer via <code>cv::Mat</code> reference counting</li>
<li>Native GRAY8 pipeline output (4× data reduction)</li>
<li>Pimpl idiom for compile-time encapsulation</li>
<li>RAII-based resource management with graceful shutdown</li>
</ul>

<p>The repository documents a complete optimization history — from a 33 FPS baseline to a sensor-limited 60 FPS — with reproducible benchmarks and architectural rationale.</p>

<h2><code>$ cat engineering_principles.md</code></h2>

<h3>Performance</h3>

<ul>
<li>Measure before optimizing</li>
<li>Profile every pipeline stage</li>
<li>Eliminate redundant memory copies</li>
<li>Prefer asynchronous over synchronous</li>
</ul>

<h3>Reliability</h3>

<ul>
<li>Fail gracefully, never crash</li>
<li>Release resources deterministically</li>
<li>Handle signals properly</li>
<li>Log everything</li>
</ul>

<h3>Maintainability</h3>

<ul>
<li>Separate interface from implementation</li>
<li>Document design decisions, not just code</li>
<li>Keep modules independently replaceable</li>
<li>Automate reproducible builds</li>
</ul>

<h3>Correctness</h3>

<ul>
<li>Verify assumptions with experiments</li>
<li>Test on real hardware, not just simulators</li>
<li>Quantify uncertainty in measurements</li>
<li>Prefer simplicity over cleverness</li>
</ul>
