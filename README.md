### Featured Project

#### [Jetson CSI + CUDA Vision Pipeline](https://github.com/taloy6/jetson-csi-cuda-vision)

A modular, real-time vision framework for the NVIDIA Jetson TX2 NX. The system integrates hardware-accelerated CSI camera capture, CUDA-based image processing, and browser-based remote visualization into a production-ready pipeline.

| Metric | Value |
| :--- | :--- |
| Sustained frame rate | 60 FPS @ 1280×720 |
| GPU utilization | ~24% |
| System power | ~5.5 W |
| End-to-end latency | ~9 ms |

The implementation is documented with a full optimization history, architectural rationale, and reproducible benchmarks. It is intended as a reference for engineers building edge vision systems on the Jetson platform.
